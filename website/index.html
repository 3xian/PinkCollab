FROM YOUR DESK TO YOUR POCKET

Three steps to a running task.

Named exactly as they appear in the Android app.

01

Choose a workspace.

Open Workspaces, browse the roots a paired host allows, and pick the project directory you want to work in.

02

Send the first prompt.

Your prompt spawns omp --mode rpc-ui inside that directory. The task joins the list right away with its live status.

03

Follow and steer.

Watch streaming replies and tool activity, then use Prompt / Steer, Interrupt, or Stop — from wherever you are.

No terminal emulator, no editor: PinkCollab is the bridge to the OMP process already running on your host.

LET’S GET YOU CONNECTED

Built for your setup.
Open from the start.

Install Oh My Pi on the host that will run the tasks, install the gateway beside it, then pair the Android app. One host and one phone at a time.

Oh My Pi, with omp --version working in your terminal.
For the gateway
Rust 1.89+ to build from source, or Node.js 18+ to install the prebuilt package. Never both.
Contributors only
JDK 17+ and Android SDK 36, needed only if you build the Android app yourself.
Read the setup guide ↗ Get a development APK ↗ A debug build from the latest successful CI run; GitHub sign-in is required. Release builds will be attached to tagged releases.
Install the gateway

Build from source

Needs Rust 1.89+
git clone https://github.com/3xian/PinkCollab.git
cd PinkCollab/gateway
cargo build --release --locked \
  --bin pinkcollab-gateway

Prebuilt gateway

npm · tagged releases
npm install -g pinkcollab

Installs a native binary — no Rust toolchain on this route. The packages ship with every tagged release. Until the first release is published, build from source.

Next steps
  1. Allow the projects your phone may browse — replace the path with your own: init --workspace /absolute/path/to/projects
  2. Start the gateway and leave the terminal open: serve
  3. Expose it over HTTPS and print a pairing code: pair --url https://gateway.example.com
  4. Open PinkCollab on Android and scan that code within 5 minutes.

Commands are the same either way: pinkcollab <command> after an npm install, ./target/release/pinkcollab-gateway <command> after a source build.

BEFORE YOU START

What PinkCollab does not do yet.

So the first surprise isn’t a surprise.

  • Managed, not adopted. A session you started by hand in a terminal cannot be attached; PinkCollab manages the tasks it spawns itself.
  • Restarts are not resurrections. Running OMP processes are not restored when the gateway restarts — those tasks show as offline, though their history stays readable.
  • Notifications are planned. Android background notifications are not implemented; a task waiting on your input only shows it while the app is open.
  • No terminal, Git client, code editor, or cloud relay. PinkCollab is a bridge to OMP on your own hosts, not an IDE and not a middleman.

POWERED BY

Oh My Pi does the work.
PinkCollab keeps you in the loop.

Oh My Pi (OMP) is a coding agent for the terminal: subagents, plan mode, LSP and DAP, hindsight memory, hashline edits, and time-traveling rules, on a native Rust engine. PinkCollab adds no agent of its own — it drives OMP on your machines and carries the conversation to your phone.

Meet Oh My Pi ↗
  • Real OMP processes. Starting a task from Android spawns omp --mode rpc-ui on the host that owns the code.
  • Your credentials stay put. Model provider keys never leave the machine — the phone talks to your gateway, not to a model.
  • No relay in the middle. HTTPS straight to your own host, via Funnel, Serve, or your own reverse proxy.
