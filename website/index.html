WHY PINKCOLLAB

A second screen.
A whole new way to work.

OMP’s /collab shares a running terminal session. PinkCollab starts and manages your sessions from Android, with model and thinking controls and provider account quotas in the same app.

⌘OMP /COLLABJoin a running sessionSHARE
VS
▣PINKCOLLAB / ANDROIDStart one from anywhereCREATE
  1. Start work, do not just watch it.

    /collab shares a session that is already running on a terminal you opened. PinkCollab creates the session itself. OMP starts there when you send the first prompt or open the model picker, so a new task can begin without a keyboard in front of the host.

  2. Persistent sessions.

    A Collab room follows one process and ends when it does. PinkCollab keeps the session in your list after OMP exits, reloads its transcript, and starts a new runtime on the same conversation later.

  3. Bring files into the conversation.

    A /collab guest cannot upload a file. Attach files from your phone with PinkCollab to give OMP the context for the next step.

  4. Reachable without a relay.

    /collab reaches guests through OMP's hosted relay, and its production relay is not distributed for self-hosting. Apart from the GitHub release check and APK download, PinkCollab talks only to the Gateway you run: Tailscale Funnel, private Serve, or your own HTTPS proxy.

  5. Swipe between live sessions.

    A /collab link opens one session. PinkCollab keeps every session in one pager: swipe to read the next one and steer it, while the others keep running.

  6. Gaps it does not close.

    PinkCollab does not mirror the TUI, and OMP stays in control of tools, files, and credentials. Use /collab when you want a colleague inside your terminal session; use PinkCollab to run your own sessions from your phone.

THE AGENT BEHIND THE APP

Oh My Pi.
The coding agent
behind PinkCollab.

Oh My Pi (OMP) is a coding agent that works in your terminal. It reads your project, edits files, and runs commands to check its work. PinkCollab connects you to that agent from your phone.

The coding capabilities come from OMP, with a native Rust core and tools for planning, code intelligence, and debugging.

LET’S GET YOU CONNECTED

From your computer.
To your pocket.

Your computer runs the sessions. Your phone keeps you connected. Prepare these three things on your computer, then follow the four steps.

Oh My Pi (OMP) ↗
Install OMP and configure your model provider. Check that omp --version works in your terminal.
Node.js 18+ ↗
Needed for the recommended npm install. No Rust or Android build tools required.
Tailscale ↗
Install it on your computer; your account must allow Funnel for remote access. Your phone does not need Tailscale.
Full setup guide ↗

Keep your computer awake and online while using PinkCollab. After pairing, you can close the terminal — the Gateway runs in the background.

Install & connectRecommended path
  1. 01

    Get the Android app

    On your phone
    Download APK ↗

    Open the downloaded APK. Allow installation from your browser if Android asks. Keep the app and Gateway on the same release.

  2. 02

    Install the Gateway

    In your computer’s terminal
    npm install -g pinkcollab@latest
pinkcollab --version

    Run as the same user who configured OMP. The version command confirms the install.

  3. 03

    Connect your project

    In your computer’s terminal

    Open a terminal in the folder containing your projects, then run:

    pinkcollab setup

    Confirm the workspace folder, sign in to Tailscale if prompted, and follow the Funnel approval link. Setup starts the Gateway and displays a QR code.

  4. 04

    Scan & start a session

    Back on your phone

    Open PinkCollab and scan the QR code within five minutes. Go to Workspaces, choose a folder, and create your first session.

    Code expired? Run pinkcollab pair on your computer for a new one.

Other ways to install

Without npm. Download your platform’s Gateway binary and verify it against SHA256SUMS on the latest release. Follow the deployment guide for platform-specific commands.

Build from source

Optional · Rust 1.89+
git clone https://github.com/3xian/PinkCollab.git
cd PinkCollab/gateway
cargo build --release --locked --bin pinkcollab-gateway

Run ./target/release/pinkcollab-gateway from gateway/ instead of pinkcollab, and build the matching Android app. See the development guide.

Already installed, or need help?

Check your connection. Run pinkcollab status for service status or pinkcollab doctor to diagnose setup problems.

Upgrade safely. Finish active sessions, then follow the upgrade and version checks. Keep the Android app and Gateway on the same release.

Need a different network setup? The deployment guide covers private Tailscale access, HTTPS proxies, platform notes, and background services.
