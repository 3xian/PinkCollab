WHY PINKCOLLAB

A second screen.
A whole new way to work.

OMP’s /collab shares a running terminal session. PinkCollab starts and manages your sessions from Android, with model and thinking controls and provider account quotas in the same app.

▣PINKCOLLAB / ANDROIDStart one from anywhereCREATE
  1. Start work, do not just watch it.

    /collab shares a session that is already running on a terminal you opened. PinkCollab creates the session itself and starts OMP in that directory, so a new task can begin without a keyboard in front of the host.

  2. Persistent sessions.

    A Collab room follows one process and ends when it does. PinkCollab keeps the session in your list after OMP exits, reloads its transcript, and starts a new runtime on the same conversation later.

  3. Bring files into the conversation.

    A /collab guest cannot upload a file. Attach files from your phone with PinkCollab to give OMP the context for the next step.

  4. Reachable without a relay.

    /collab reaches guests through OMP's hosted relay, and its production relay is not distributed for self-hosting. PinkCollab talks only to the Gateway you run: Tailscale Funnel, private Serve, or your own HTTPS proxy.

  5. Swipe between live sessions.

    A /collab link opens one session. PinkCollab keeps every session in one pager: swipe to read the next one and steer it, while the others keep running.

  6. Gaps it does not close.

    PinkCollab does not mirror the TUI, and OMP stays in control of tools, files, and credentials. Use /collab when you want a colleague inside your terminal session; use PinkCollab to run your own sessions from your phone.

The coding capabilities come from OMP, with a native Rust core and tools for planning, code intelligence, and debugging.

LET’S GET YOU CONNECTED

From your computer.
To your pocket.

Download the Android release APK, install the Gateway on the computer that will run sessions, and install and configure Oh My Pi (OMP) separately on that host. Run guided setup, scan the QR code, and close the terminal. The Gateway runs in the background.

Install and connect

Install with npm

Easiest · Node.js 18+
npm install -g pinkcollab@latest
node "$(npm root -g)/pinkcollab/bin/check-install.js"
cd ~/projects
pinkcollab setup

Installs the released native Gateway binary without Rust. Run the PATH check after npm finishes and resolve any warning before setup.

PowerShell & direct downloads

PowerShell users: use node (Join-Path (npm root -g) "pinkcollab/bin/check-install.js") and inspect Get-Command pinkcollab -All. Prefer a direct download? Choose your platform’s Gateway binary and verify it against SHA256SUMS on the latest release.

Build from source (optional)

Needs Rust 1.89+
git clone https://github.com/3xian/PinkCollab.git
cd PinkCollab/gateway
cargo build --release --locked --bin pinkcollab-gateway
Next steps
  1. Check omp --version, then run pinkcollab setup from your projects directory. Confirm the workspace and sign in to Tailscale if prompted.
  2. Scan the QR code in PinkCollab on Android within five minutes. Setup can generate another code if it expires.
  3. Close the terminal after pairing. Choose a workspace in the app and create your first session.
  4. Check the host with pinkcollab status; investigate problems with pinkcollab doctor. Pair another phone with pinkcollab pair.
Platform notes & upgrades

On macOS, we recommend brew install tailscale, followed by sudo brew services start tailscale and tailscale up; complete sign-in and verify with tailscale status. Existing Tailscale.app users can keep using it.

Windows service installation needs an administrator terminal as the same user, service login credentials and the Log on as a service right. macOS starts at login; Linux user services may stop on logout. See the deployment guide for details.

After an npm upgrade, verify pinkcollab --version matches the installed package before running pinkcollab setup or pinkcollab service install again. A different copy on PATH can still run the old version; see duplicate-installation checks. Updates may stop active OMP runtimes; stored sessions and pairings remain. Afterward, pinkcollab doctor must show matching CLI and installed-binary hashes; start a stopped service with pinkcollab service start.

Manual Tailscale Serve and HTTPS proxies are also supported. Their remote access is reported as externally managed, not verified; PinkCollab checks Funnel only when it configured that mapping.

For a source build, run ./target/release/pinkcollab-gateway from gateway/ instead of pinkcollab, and build the matching Android app from source. For a direct release download, use ./pinkcollab-gateway-<your-platform> from its download directory after chmod +x on macOS/Linux; on Windows PowerShell use .\pinkcollab-gateway-win32-x64.exe from its download directory.
