HOW IT WORKS

Phone in hand. OMP on your host.

PinkCollab connects your Android app to a Gateway on your own computer or server. The Gateway starts and controls Oh My Pi tasks; it is not another coding agent.

  1. Connect over HTTPS

    Android reaches an HTTPS/WSS front end. Tailscale Serve is private to your tailnet, Funnel is public, or you can use your own reverse proxy. Each forwards to the Gateway’s loopback HTTP listener; the Gateway itself does not handle TLS.

  2. Run OMP on the host

    After checking the paired device and allowed workspace, the Gateway starts one omp --mode rpc-ui process per task. Commands and live events travel between the Gateway and OMP as NDJSON. OMP makes model requests using the provider configuration on the host, not on the phone.

  3. Keep control of access and state

    The Gateway stores pairings and task metadata in SQLite. OMP owns its session history. Pairing codes are single-use and expire after five minutes; you can revoke a phone’s host-side credential. Workspace roots limit Gateway browsing and task creation, not the OS permissions of OMP.

The Gateway does not reattach running OMP processes after a restart. For networking and revocation details, read the deployment guide; for requests and events, read the protocol reference.
