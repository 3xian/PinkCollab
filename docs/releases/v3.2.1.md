PinkCollab v3.2.1: richer live tool intents and session information on Android

## Highlights

- Tap the selected Android session card again to open a read-only summary with its full title, host, working directory, status, local creation/update times, and session ID. The dialog follows session identity across list reordering and reflects refreshed metadata.
- The All hosts control's clickable left edge now aligns with the first session card.

## Fixes

- Live tool calls now retain descriptive intent from the assistant's original arguments, matching saved history instead of falling back to generic Read or Edit titles when execution events omit that text. Blank intent fields no longer hide a later nonblank description.
- Late tool metadata preserves completed/error states and results without recreating calls retired from the live timeline or displaying declarations that never executed. Retired calls remain available through durable details.
- Switching sessions or removing the summarized session dismisses its dialog without reopening it on later list updates.

## Upgrade

- Update both Android and the Gateway to receive all fixes. Finish active work, then run `npm install -g pinkcollab@3.2.1` and `pinkcollab update` under the existing OS user, retaining `--data-dir` when applicable. Restarting the Gateway ends active OMP runtimes but preserves stored sessions and pairings.
- Android/Gateway Protocol 4 and the database schema are unchanged. Install the signed Android APK over the existing app; do not uninstall it.
