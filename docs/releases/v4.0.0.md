PinkCollab v4.0.0: continuous activity timelines and lighter session presentation

## Highlights

- Consecutive reads, searches, edits and commands appear in one continuous activity timeline. Current actions update in place, and the focused step opens a bounded preview without loading full tool output.
- Replies fold earlier activity disclosures; completed sequences show observed tool-call counts while preserving failure and unfinished-call evidence. Individual previews remain manually expandable.
- User prompts use inset surfaces, agent replies remain open, and the fixed work-status row keeps duration and token speed while live actions appear in the timeline.
- Session catalog bootstrap and refresh reuse matching-version cached summaries and reject stale or mixed-version responses.

## Fixes

- Tool previews follow animated height changes so the latest step stays clear of the composer while following live work.
- Anchored edit summaries recognize bare or enveloped patches with LF or CRLF line endings. Replacement lines beginning with `+++` remain visible and are not mistaken for file paths.
- The concise Android projection no longer builds unused full-output strings or synthesized diffs. Debug/raw rendering retains original tool payloads and full-detail loading.

## Upgrade

- Protocol 4 and the database schema are unchanged. The optional tool-summary preview field is backward compatible. Install the signed Android APK over the existing app; do not uninstall it.
- Gateway and npm packages use the aligned version 4.0.0. To update the Gateway, finish active work, run `npm install -g pinkcollab@4.0.0`, then `pinkcollab update` under the existing OS user, retaining `--data-dir` when applicable. Restarting the Gateway ends active OMP runtimes but preserves stored sessions and pairings.
