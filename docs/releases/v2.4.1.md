PinkCollab v2.4.1: reliable model-picker errors and clearer sending status

## Fixes

- Stop briefly showing a failed-start message when choosing another model before OMP's startup status arrives.
- Show explicit startup failures even when the app does not observe an intermediate starting state. Retrying or reopening the model picker clears previous startup errors.
- Show message submission and file-upload progress in the work-status strip, including the current file index, count, and filename. Use a neutral text shimmer instead of the composer's progress bar.

## Compatibility and upgrade

- Protocol 3 is unchanged.
- Install the signed Android APK over the existing app to preserve phone-side pairings.
- Update the Gateway with `npm install -g pinkcollab@2.4.1`, then run `pinkcollab setup` or `pinkcollab service install` to update an existing background service. Restarting a Gateway stops active OMP runtimes; stored sessions and pairings remain.
