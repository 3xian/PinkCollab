PinkCollab v3.0.5: compact Android layout refinements

## Highlights

- The model picker's heading now shares one row with the Reload and Usage actions. The heading keeps its full text, while the actions use the remaining width and wrap onto extra lines when space is tight.
- Workspace rows on the Resources screen show the complete path as their only content. Rows are shorter than before, and long paths wrap so the final directory stays visible.
- Activity card chevrons share the message copy action's vertical column, so both right-hand conversation controls line up.
- Host cards on the Resources screen carry no border; they keep the glass gradient fill and wallpaper art.

## Fixes

- At narrow widths or large font scales, the model picker no longer clips or squeezes its heading, and Reload/Usage stay reachable.
- Long workspace paths are no longer truncated to a single line, so directories sharing a prefix remain distinguishable.

## Compatibility and upgrade

- Protocol 4 is unchanged. Build or upgrade Android and the Gateway from the same release.
- Install the signed Android APK over the existing app to preserve pairings and app data; do not uninstall the production app.
- The npm launcher and all five platform packages are published as 3.0.5. Update with `npm install -g pinkcollab@3.0.5`.
