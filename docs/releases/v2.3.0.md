PinkCollab v2.3.0: clearer Android activity cards

## Highlights

- See each operation's outcome in a compact, slightly overlapping horizontal row of status icons. Long activity groups remain scrollable, and newly appended operations animate into view.
- Tap an activity card to expand or collapse it, rather than aiming for a small chevron. Individual output controls and horizontal scrolling keep their own interactions.

## Fixes

- Keep the collapse chevron beside the activity header when expanding long operation lists, instead of moving it off-screen halfway down the details.
- Give expanded operation details the full content width and match the chevron's right inset to the title's left inset.
- Simplify expanded task plans to phase headings, progress counts, and task rows by removing the redundant QUEST LOG summary and raw arguments/output expander.

## Compatibility and upgrade

- Protocol 3 and database schema 5 are unchanged; no data migration is required. These presentation improvements are Android-only, and existing v2.2.0 Gateways remain compatible.
- Install the signed Android APK over the existing app to preserve phone-side pairings. Debug builds cannot upgrade production APKs because their signing certificates differ.
- To update the Gateway release version, use `npm install -g pinkcollab@2.3.0`, then run `pinkcollab setup` or `pinkcollab service install` to update an existing background service. Restarting a Gateway stops active OMP runtimes; stored sessions and pairings remain.
