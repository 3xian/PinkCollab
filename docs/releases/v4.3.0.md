PinkCollab v4.3.0: discover OMP slash commands and retain local command output

## Highlights

- Type `/` in the Android composer to discover commands from the attached OMP runtime. Suggestions match names and aliases; selecting a command inserts its canonical name without sending, and arguments remain ordinary editable text.
- Local slash commands can complete without an agent turn. Their output appears as command output rather than an assistant reply and is retained in history across runtime exit, session reopening and Gateway restart.
- Host connections recover on app foreground and network restoration, without automatically resending prompts.
- The compact TODO header shows settled/total counts and the current active task. Work-status icons have clearer spacing before their labels.

## Fixes

- Command catalogs are scoped to their runtime generation; stopping or replacing a runtime invalidates cached commands and rejects late discovery results. Loading failures, empty catalogs and unknown spellings do not block normal Send.
- Gateway applies command-driven model/settings updates and title events. Commands that would invalidate Gateway-owned history or working-directory mappings are rejected; an unexpected transcript switch stops the runtime without adopting the new history.
- Attention feedback and command outputs share one transactional local timeline ledger and sequence order. Delivered attention responses commit their durable record and receipt together.
- If command output cannot be anchored or saved, Gateway suppresses its normal publication, fences and stops that runtime generation, and records affected in-flight prompts as unknown when receipts can be saved. Late completion cannot overwrite the persistence failure, and Stop remains available.

## Upgrade

- Update both Android and Gateway to 4.3.0 for slash-command discovery. Protocol 4 is retained. The Gateway database migrates to schema 10, which older Gateway versions cannot open; back up the Gateway data directory before upgrading if rollback may be needed. Migration preserves existing feedback and command-output identities, history anchors and ordering.
- Install the signed Android APK over the existing app; do not uninstall it. To update Gateway, finish active work, run `npm install -g pinkcollab@4.3.0`, then `pinkcollab update` under the existing OS user, retaining `--data-dir` when applicable. Restarting Gateway ends active OMP runtimes but preserves stored sessions and pairings.
