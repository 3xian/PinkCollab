PinkCollab v0.2.0 — persistent sessions on a new Gateway API

## Highlights

- Creating a session saves the conversation without starting OMP. The first prompt starts OMP; Start attaches a process without sending a prompt.
- The session page keeps a live view separate from saved OMP history.
- Stop waits until the OMP process tree has exited. `leases` and `clear-lease` cover an unclean Gateway exit.
- `setup-funnel` is now `funnel`.
- The startup screen plays the login animation.

## Fixes

- After an uncertain response, the running app checks the original command receipt before resending. Pending retries are not kept across an app restart.

## Upgrade

Install the 0.2.0 Android app and Gateway together. A 0.1.x app will not work with this Gateway. Stop the previous Gateway and its OMP processes before the first 0.2.0 start. That start keeps host identity, pairings, and session metadata, and writes a SQLite backup next to the database. Do not point a 0.1.x Gateway at the migrated database; restore that backup to roll back.
