PinkCollab v3.0.4: durable attention responses and clearer Android conversation details

## Highlights

- Answered attention requests now remain in the conversation as durable feedback, with the original question and exact answer. Selections, confirmations, text/editor submissions and cancellations survive Gateway restarts and session reopening without modifying OMP's transcript.
- Feedback keeps the same identity in live and saved history, follows the active branch, and is not duplicated when a command is replayed. Responses before OMP creates a JSONL file remain readable and survive resume.
- Android conversation text uses a 12sp Maple Mono size. Single-tool activity details open directly with the activity card, current-work labels transition smoothly, and the floating Todo panel uses a borderless raised surface.

## Fixes

- A blocked attention-response write no longer blocks session snapshots or emergency Stop. Feedback and history ordering are separate from runtime lifecycle locking.
- Whitespace-only answers are preserved and copyable; only zero-length answers display the empty-response placeholder.
- The website's setup-guide and APK links share a wrapping action row with consistent spacing.

## Compatibility and upgrade

- Protocol 4 is unchanged. Build or upgrade Android and the Gateway from the same release.
- The Gateway database migrates automatically to schema 7 to distinguish feedback-only sessions from missing expected OMP history. Existing possibly written mappings remain protected; corrupt or missing expected transcripts still fail explicitly. Back up the Gateway data directory before upgrading. Older Gateways supporting only schema 6 cannot open the migrated database; do not downgrade in place.
- Install the signed Android APK over the existing app to preserve pairings and app data; do not uninstall the production app.
- The npm launcher and all five platform packages are published as 3.0.4. Update with `npm install -g pinkcollab@3.0.4`.
