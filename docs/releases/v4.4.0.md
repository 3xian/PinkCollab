PinkCollab v4.4.0: choose when to restart the Gateway after updating

## Highlights

- `pinkcollab update` stages the installed Gateway, then asks before restarting or starting it. Press Enter or close stdin to leave the running or stopped service as it is. Run `pinkcollab service restart` when ready.
- Before a confirmed restart, the CLI rechecks which data directory owns the service. On Windows, it restores the old executable if replacement fails after moving it to the backup path, or prints manual recovery instructions if restoration fails.

## Upgrade

- Install `pinkcollab@4.4.0` and run `pinkcollab update` as the existing OS user, keeping `--data-dir` if applicable. Answer `y` only after active work finishes: restarting ends active OMP runtimes but preserves stored sessions and pairings.
- Install the signed Android APK over the existing app.
