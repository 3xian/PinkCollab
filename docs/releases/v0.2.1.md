PinkCollab v0.2.1 — file attachments and clearer session controls

## Highlights

- Attach up to five files to a prompt. The Gateway stores them for that session and passes host paths, or recognized images, to OMP.
- Creating a session starts OMP immediately. The composer actions are Stop, Exit, and Send.
- From Sessions, Conf can check GitHub for an app update, show these notes, and open the APK. Startup checks at most once a day.
- Pending commands are stored before they are sent, so a lost response can be reconciled after the app restarts.

## Fixes

- A detached session no longer says there are no saved messages while history is still loading, or after that fetch fails.
- A Start after Exit or a settled failure sends a new command instead of replaying the old receipt.
- Host addresses stay hidden until revealed.
- Reconnecting keeps the retry state visible until the next snapshot arrives.

## Upgrade

Install the 0.2.1 app and Gateway together to use file attachments. The 0.2.0 database schema is unchanged, and existing pairings stay. Stop the previous Gateway before starting 0.2.1.
