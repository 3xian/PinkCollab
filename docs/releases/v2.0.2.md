PinkCollab v2.0.2: optimize Android conversation updates and add a frosted composer backdrop

## Highlights

- Android conversation screens now parse Markdown in the background, reuse a bounded rendering cache, and coalesce cumulative conversation updates while keeping input and controls responsive to state changes.
- Android release builds now enable code and resource shrinking to reduce APK size.
- The Android input area now has a lightly dimmed, frosted background on Android 12 and later. Blur fades in above the composer, keeps text and buttons sharp, and follows visible pages during session swipes. Earlier Android versions retain the original gradient backdrop.

## Fixes

- Keep newly created sessions selected while the session list and pager catch up.
- Preserve the preceding formatted Markdown while an edited message is being rendered; obsolete rendering jobs cannot overwrite newer results.

## Compatibility and upgrade

- Protocol 3 and database schema 5 are unchanged. Android, Gateway, and npm package versions are updated together; no data migration is required.
- Install the signed Android APK over the existing app to preserve phone-side pairings.
- Upgrade the Gateway with `npm install -g pinkcollab@2.0.2`, then run `pinkcollab setup` or `pinkcollab service install` to update an existing background service. Restarting a Gateway stops active OMP runtimes; stored sessions and pairings remain.
