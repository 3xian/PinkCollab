PinkCollab v4.5.0: browse host session models on Android without taking ownership

## Highlights

- Open Models to browse and search while the conversation stays open on the host. Only Apply changes settings. If the host owns the session, close it there and tap Apply again; Android keeps the search and selection.
- Each Apply has its own receipt. Rotating the device preserves a pending submission without sending it twice. If a refreshed catalog no longer offers the selected model or thinking level, Android asks for a new choice.

## Compatibility and upgrade

- Gateway checks idle session ownership with OMP 18.14.1 or newer. Older versions rely on transcript activity checks. If the detached catalog cannot honor the host’s model or extension configuration, use Models in an attached session instead.
- Update both components: install `pinkcollab@4.5.0`, run `pinkcollab update` as the existing Gateway user, and install the signed APK over the current app. Wait for active work to finish before confirming a Gateway restart.
