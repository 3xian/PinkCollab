PinkCollab v2.4.0: Fast mode controls and clearer model defaults

## Highlights

- Toggle OMP Fast mode directly from the Android composer. The runtime reports both the saved preference and whether Fast mode is currently active.
- Detached conversations show `OMP default`. Start OMP from the model picker to choose another model, or keep the default and send your next message.
- Resumed conversations use the newly started OMP process's default model instead of restoring the historical model selection.
- Refresh the app logo, Android launcher icons, website icons, and promotional artwork, including adaptive Android launcher icons.

## Fixes

- Keep runtime initialization failures visible in the model picker and allow retrying, including failures after the process has attached.
- Give the composer Stop, Exit, and Send controls separate touch targets and show quota usage inside a progress bar with provider update times.
- Simplify timeline loading indicators and refine task-plan spacing and toolbar controls.

## Compatibility and upgrade

- Protocol 3 is unchanged. Update Android and Gateway together to use Fast mode; the configured OMP version must support `set_fast_mode`.
- Install the signed Android APK over the existing app to preserve phone-side pairings.
- Update the Gateway with `npm install -g pinkcollab@2.4.0`, then run `pinkcollab setup` or `pinkcollab service install` to update an existing background service. Restarting a Gateway stops active OMP runtimes; stored sessions and pairings remain.
