PinkCollab v2.4.3: clearer Android session recovery and consistent message copying

## Highlights

- Android shows a dedicated recovery screen when paired hosts cannot supply session lists, with plain-language connection details and actions to retry, pair again, or check for an app update.
- Workspace cards use platform-specific artwork and show active session counts for connected hosts. The pairing action uses the standard primary button size.
- The website and README feature refreshed, optimized product artwork and simpler onboarding.

## Fixes

- Keep session recovery visible during retries and after returning from Workspaces. Retry only failed hosts, leaving hosts that are connecting, syncing, or already online and synchronized alone.
- Distinguish active connection attempts from offline retry waits. Persistent connection failures are checked at intervals capped at 15 seconds.
- Identify connection failures by typed causes so recovery hints do not depend on diagnostic wording.
- Give timeline messages consistent copy controls and feedback that survives streaming text updates.

## Compatibility and upgrade

- Protocol 3 is unchanged. Install the signed Android APK over the existing app to preserve phone-side pairings.
- Update the Gateway with `npm install -g pinkcollab@2.4.3`.
- Run `pinkcollab setup` or `pinkcollab service install` to update an existing background service. Changed running services restart and stop active OMP runtimes; stored sessions and pairings remain.
