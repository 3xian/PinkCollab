PinkCollab v3.0.3: restored graphite Android visuals and reliable large-text session layouts

## Highlights

- Restored graphite surfaces, purple/pink accents, rounded glass panels and the original startup artwork across the Android app, replacing the 3.0.2 antique visual redesign.
- Kept the 3.0.2 runtime recovery, startup readiness, current-work presentation and accessibility semantics. Conversation backgrounds remain static.
- Conversation bodies share an 11sp Maple Mono size; existing Markdown views update when conversation typography changes. Message text uses the full body width, with a separate copy-action footer.

## Fixes

- Earlier-history refresh feedback stays below the pinned Todo header without reducing the conversation's scrollable viewport, including at enlarged font sizes.
- Session-card directories and statuses have independent width budgets, so long connection statuses cannot hide the workspace directory at enlarged font sizes.

## Compatibility and upgrade

- Gateway behavior, protocol 4 and database schema 6 are unchanged from 3.0.2.
- Install the signed Android APK over the existing app to preserve pairings and app data; do not uninstall the production app.
- The npm launcher and all five platform packages are published as 3.0.3. Update with `npm install -g pinkcollab@3.0.3`.
