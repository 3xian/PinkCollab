PinkCollab v3.3.1: token throughput and clearer connection and thinking indicators

## Highlights

- Android's work-status strip shows output-token throughput from the latest completed assistant message when OMP provides usage and timing. The final sample stays visible after work settles; new work clears it. Unavailable samples display `… tok/s` rather than estimating tokens from text.
- The composer shows a compact thinking-effort gauge beside the model name, with distinct indicators for automatic and unknown levels. The indicator shares the model name's enabled and disabled colors.
- Session info shows the host's live connection status immediately after its name, using the same wording and colors as the host filter list.

## Fixes

- Timeline regression checks exclude the composer placeholder when the latest user instruction appears in both surfaces.

## Upgrade

- Protocol 4 adds the optional runtime field `tokensPerSecond`; the database schema is unchanged. Update Android and the Gateway together to display throughput. Install the signed Android APK over the existing app; do not uninstall it.
- Gateway and npm packages use the aligned version 3.3.1. To update the Gateway, finish active work, run `npm install -g pinkcollab@3.3.1`, then `pinkcollab update` under the existing OS user, retaining `--data-dir` when applicable. Restarting the Gateway ends active OMP runtimes but preserves stored sessions and pairings.
