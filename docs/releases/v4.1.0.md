PinkCollab v4.1.0: a compact paper-style Android interface and steadier live timelines

## Highlights

- Android adopts light paper surfaces, charcoal headers and controls, restrained rose accents, compact typography and softer shadows across sessions, tasks, pairing and resources.
- Refreshed robot artwork, launcher icons and empty states carry the updated identity into Android, the website and README.
- The website presents a shorter guided installation path with separate setup routes, clearer upgrade and troubleshooting links, and refreshed usage artwork.

## Fixes

- Live timelines follow measured layout changes as Markdown replies grow and tool previews expand or collapse, keeping the latest content above the composer.
- Scrolling backward or opening an activity disclosure preserves the reading position. Following resumes when the user scrolls forward to the end; layout changes alone no longer resume it.
- Timeline rows retain their fade-in without placement animation competing with bottom following.

## Upgrade

- Protocol 4 and the database schema are unchanged. Install the signed Android APK over the existing app; do not uninstall it.
- Gateway and npm packages use the aligned version 4.1.0; Gateway behavior is unchanged from 4.0.1. To update the Gateway, finish active work, run `npm install -g pinkcollab@4.1.0`, then `pinkcollab update` under the existing OS user, retaining `--data-dir` when applicable. Restarting the Gateway ends active OMP runtimes but preserves stored sessions and pairings.
