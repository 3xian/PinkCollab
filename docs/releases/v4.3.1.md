PinkCollab v4.3.1: safely recover orphaned runtime leases

## Fixes

- Startup and session deletion share orphan-lease recovery. Windows verifies that the recorded Job Object no longer exists; Linux verifies a boot change or absence of the entire recorded process group.
- Confirmed runtime exit marks unfinished generation receipts as outcome unknown and releases the lease in one transaction.
- Deleting an inactive session with an unverified runtime lease returns runtime_exit_unconfirmed instead of treating inactivity as proof of process exit. Legacy leases remain blocked until verified manual recovery.

## Upgrade

- The Gateway database migrates to schema 11, which older Gateway versions cannot open. Back up the Gateway data directory before upgrading if rollback may be needed. Existing leases without process identity remain unverified.
- Finish active work, run `npm install -g pinkcollab@4.3.1`, then `pinkcollab update` under the existing OS user, retaining `--data-dir` when applicable. Restarting Gateway ends active OMP runtimes but preserves stored sessions and pairings. Protocol 4 is retained.
- Install the signed Android APK over the existing app; do not uninstall it.
