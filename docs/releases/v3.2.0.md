PinkCollab v3.2.0: filter sessions by host and update the Gateway without reconfiguration

## Highlights

- Android Tasks now offers an All hosts / individual host filter. The session strip, conversation pager, and older-session loading follow the selected host. The filter survives state restoration and returns to All hosts when navigating to another host's session.
- The collapsed TODO panel is smaller and keeps progress in a single compact header; expanding it still exposes phases and task details.
- Discovered OMP conversations are labeled On host / Session on host instead of History, distinguishing their source without claiming that an external OMP process is running.
- `pinkcollab update` applies the installed CLI to an existing background Gateway without rerunning setup or changing configuration. A stopped service stays stopped; a running service restarts only when the installation changes.

## Upgrade

- Finish active work, then run `npm install -g pinkcollab@3.2.0` and `pinkcollab update`. Use the existing OS user and `--data-dir` when applicable. A restart ends active OMP runtimes but preserves stored sessions and pairings.
- `update` requires an existing configuration and installed background startup. For a new installation, use `pinkcollab setup`; for foreground-only operation, replace the binary and restart it manually.
- Android/Gateway Protocol 4 and the database schema are unchanged. Install the signed Android APK over the existing app; do not uninstall it.
