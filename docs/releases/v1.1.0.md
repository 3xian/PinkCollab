PinkCollab v1.1.0 — guided setup and a background Gateway

## Highlights

- Run `pinkcollab setup` from your projects directory to configure workspaces, check OMP, connect Tailscale, configure Funnel, install the background Gateway, and pair your Android phone by QR code.
- Manage the background Gateway with `pinkcollab service install/start/stop/restart/status/uninstall` on macOS, Linux, and Windows. The service uses a stable binary outside the npm installation directory.
- Use `pinkcollab status` for operational status and `pinkcollab doctor` for detailed diagnostics. Manual HTTPS proxies and private Tailscale Serve remain supported and are identified as externally managed.
- Automate setup with `--non-interactive --workspace <directory>` when Tailscale is already connected. Pair phones separately with `pinkcollab pair`.

## Reliability

- Setup checks service ownership and listener conflicts before changing configuration or remote access.
- Interrupted service updates retain pending activation and can be retried without losing the required restart.
- Administrative command timeouts cover output collection, including inherited output handles held by child processes.
- Configuration and installation metadata are replaced atomically. Repeated setup merges workspace roots and retains paired devices and stored sessions.

## Compatibility and upgrade

- Protocol 3, the session/runtime/operation model, WebSocket API, and database schema remain unchanged from 1.0.0. Install the Android APK and Gateway from this release together.
- Upgrade with `npm install -g pinkcollab@1.1.0`, then run `pinkcollab setup` or `pinkcollab service install` to update an installed background Gateway. Changed running services restart, stopping active OMP runtimes; stored sessions and pairings remain.
- OMP and Tailscale are separate dependencies. Guided setup uses public Tailscale Funnel and requires a tailnet that permits it; manual Serve or HTTPS proxy deployments can continue using the manual commands.
- macOS services start at login. Linux user services may stop on logout without lingering. Windows service installation requires an administrator terminal as the same user, explicit service login credentials, and the Log on as a service right; install interactively before using non-interactive setup.
- Existing remote URLs without PinkCollab's Funnel tracking are reported as externally managed, not verified. Rerun `pinkcollab funnel` to adopt a managed Funnel mapping.
