PinkCollab v2.0.3: clarify Android connection status and improve session loading

## Highlights

- Pull down at the top of a conversation to load earlier messages, with a loading indicator replacing the "Load earlier messages" button.
- Android now distinguishes opening a connection from synchronizing sessions and directories. Automatic reconnects show the attempt number and the most recent connection failure.
- The conversation composer uses a dimmed gradient backdrop instead of the frosted blur introduced in v2.0.2.

## Fixes

- Keep connection feedback visible when previously loaded workspace directories are still displayed.
- Cancel obsolete session-detail requests when switching sessions and clear their loading errors.
- Keep message history in a loading state while reconnecting instead of showing a premature failure and retry prompt.
- Expose “Load earlier messages” as a conversation accessibility action with the same loading guard as pull-to-load.
- Preserve inline-code foreground-only styling in optimized Android builds and cover it with a release-shrinker regression check.
- Keep OMP write-timeout failures from being replaced by generic crash reports during concurrent shutdown.

## Compatibility and upgrade

- Protocol 3 and database schema 5 are unchanged; no data migration is required.
- Install the signed Android APK over the existing app to preserve phone-side pairings.
- Upgrade the Gateway with `npm install -g pinkcollab@2.0.3`, then run `pinkcollab setup` or `pinkcollab service install` to update an existing background service. Restarting a Gateway stops active OMP runtimes; stored sessions and pairings remain.
