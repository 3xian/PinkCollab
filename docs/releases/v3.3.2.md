PinkCollab v3.3.2: floating session switcher and compact conversation controls

## Highlights

- Session cards float above the conversation with a fading background, allowing earlier messages to scroll behind the strip while keeping the first message clear of it.
- Cards show status in the top-right corner and the phone's host name beside the project directory on the second line. Long labels truncate independently.
- Composer action buttons use a more compact layout, and timeline timestamps use a quieter gray.

## Fixes

- Expanded Todo plans account for the session-card inset when calculating available height, keeping the panel above the composer in short viewports. The task list remains independently scrollable.
- Host-filter UI checks assert the selected label on the control's merged accessibility semantics rather than requiring a separate descendant node.

## Upgrade

- The protocol and database schema are unchanged. Install the signed Android APK over the existing app; do not uninstall it.
- Gateway and npm packages use the aligned version 3.3.2. To update the Gateway, finish active work, run `npm install -g pinkcollab@3.3.2`, then `pinkcollab update` under the existing OS user, retaining `--data-dir` when applicable. Restarting the Gateway ends active OMP runtimes but preserves stored sessions and pairings.
