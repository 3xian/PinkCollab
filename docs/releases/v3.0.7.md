PinkCollab v3.0.7: compact directory browsing and phone-local host names

## Highlights

- The directory browser is a compact list instead of a stack of cards. Its title is the phone's host name, or Browse workspace when that name is blank. Breadcrumb tags show the workspace root and each directory inside it. Back, the parent tag, and the top bar all use the loaded listing's parent. A deeper tag opens a directory only when that path was already returned by the server.
- Create session stays docked and names the current folder, including in an empty directory. Pull to refresh keeps the current listing visible if the refresh fails. A search field appears once a listing has seven or more folders.
- A phone-local host name is stored with the pairing and shown instead of the Gateway name. Host snapshots keep that name. Setting it back to the Gateway name removes the override.
- Long-press a message to copy its source text. There is no copy button. A short toast confirms the copy.

## Fixes

- Each host makes at most three connection attempts in one cycle, one second apart, then stays offline. Manual refresh, returning to the foreground, or the default network becoming available starts a new cycle. It no longer keeps checking on a timer.
- Linux host cards show the word Linux. The Tasks status stays at the trailing edge of the card strip.

## Compatibility and upgrade

- Protocol 4 is unchanged. The Gateway database schema is unchanged. Build or upgrade Android and the Gateway from the same release.
- Install the signed Android APK over the existing app to preserve pairings and app data; do not uninstall the production app. A phone-local host name is stored only on the phone and does not change the Gateway.
- The npm launcher and all five platform packages are published as 3.0.7. Update with `npm install -g pinkcollab@3.0.7`.
