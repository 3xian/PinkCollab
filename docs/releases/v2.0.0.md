PinkCollab v2.0.0: discover and continue host OMP conversations from your phone

## Highlights

- Existing OMP conversations appear in Tasks as **History**. Open saved messages without starting a runtime, then send a message or start the session to continue it. No manual import is required.
- Discovery respects the Gateway workspace allowlist and selected OMP profile or absolute session directory. Continuing a conversation preserves its identity and saved history.
- Android orders active sessions by creation time and inactive sessions by update time, with refined timeline typography, Markdown emphasis, activity icons, and composer styling.

## Fixes

- Android replaces non-blocked host connections when returning to the foreground or when a network becomes available, recovering stale sockets.
- Guided setup supports interactive Tailscale Funnel onboarding.

## Compatibility and upgrade

- Install the Android APK and Gateway from this release together. Protocol 3 remains in use; session snapshots add an origin field and the Gateway database migrates to schema 5 for conversation adoption and ownership tracking.
- Upgrade with `npm install -g pinkcollab@2.0.0`, then run `pinkcollab setup` or `pinkcollab service install` to update an existing background service. Restarting a Gateway stops active OMP runtimes; stored sessions and pairings remain.
- Close the external OMP instance before continuing its conversation from PinkCollab. Concurrent use of the same history by external OMP and PinkCollab is unsupported; writer checks do not establish exclusive ownership across applications.
- Discovery supports OMP version-3 file-backed session history and was checked against OMP 18.4.2. Only conversations visible to the Gateway account, within its configured workspace allowlist and selected storage, are eligible. Custom storage layouts may require an absolute `--session-dir`.
