PinkCollab v2.2.0: floating task plans on Android

## Highlights

- Follow the latest task plan in a floating panel above the conversation. Expand it to see phases, task statuses, blockers, and completed or dropped tasks without shifting messages.
- Keep task progress current with structured Todo snapshots from the Gateway, including saved history and live updates. A newer empty or unavailable snapshot clears the previous plan.
- Collapse the plan with Back, by tapping outside it, or by focusing the message composer. Settled plans briefly highlight completion before collapsing automatically.

## Fixes

- Mark the current model in the model picker, show Done when settings are unchanged, and explain why model settings are temporarily unavailable.
- Keep APK download progress visible while scrolling long release notes in the Android update dialog.
- Consolidate OMP discovery and adoption guidance and refresh website assets and content.

## Compatibility and upgrade

- Protocol 3 and database schema 5 are unchanged; no data migration is required. Upgrade both Android and the Gateway to receive structured task plans. Older Gateways do not provide the new snapshots.
- Install the signed Android APK over the existing app to preserve phone-side pairings. Debug builds cannot upgrade production APKs because their signing certificates differ.
- Upgrade the Gateway with `npm install -g pinkcollab@2.2.0`, then run `pinkcollab setup` or `pinkcollab service install` to update an existing background service. Restarting a Gateway stops active OMP runtimes; stored sessions and pairings remain.
