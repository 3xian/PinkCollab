PinkCollab v2.4.2: smoother model startup, clearer attention cards, and reliable install checks

## Highlights

- Opening Models for an inactive session starts OMP directly. Startup progress survives closing and reopening the picker without duplicating a pending start; command errors and unconfirmed outcomes remain visible with Retry, even without a detailed failure receipt.
- Attention requests use inset cards with proportional question text and full-width, wrapping selection options. The composer action rail is ordered End, Stop, Send; End confirms runtime termination, while Stop interrupts the current turn.
- Activity icons fade in with staggered entrances without scaling. Scrolling to an offscreen icon no longer restarts an expired entrance delay. Active task dots breathe without changing layout bounds.

## Fixes

- Keep retained conversation content visible while a session subscription refreshes without incorrectly reporting an online host as offline.
- Add an explicit npm launcher PATH diagnostic that detects shadowing installations, including relative PATH entries. Run it directly after installation; npm lifecycle scripts modify PATH and cannot reliably represent the caller's shell.

## Compatibility and upgrade

- Protocol 3 is unchanged. Install the signed Android APK over the existing app to preserve phone-side pairings.
- Update with `npm install -g pinkcollab@2.4.2`, then run `node "$(npm root -g)/pinkcollab/bin/check-install.js"` from your shell. In PowerShell, use `node (Join-Path (npm root -g) "pinkcollab/bin/check-install.js")` and inspect `Get-Command pinkcollab -All`. Resolve any warning before running setup.
- Run `pinkcollab setup` or `pinkcollab service install` to update an existing background service. Changed running services restart and stop active OMP runtimes; stored sessions and pairings remain.
