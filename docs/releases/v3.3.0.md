PinkCollab v3.3.0: in-place host refresh and faster session creation on Android

## Highlights

- Refresh the selected host, or all hosts, directly beside the Tasks host filter without leaving the current session. The filter background shows proportional batch progress; authentication-required and upgrade-required hosts retain their dedicated recovery actions.
- Open Session info from the selected session card and choose New session here to create a fresh conversation in the same host and working directory.
- An empty composer shows the latest user instruction from the conversation as a single-line, ellipsized placeholder. Drafts still support multiple lines.

## Fixes

- Refresh completion is tracked outside the screen lifecycle. Backgrounding the app during a retry no longer leaves refresh disabled when the host returns to the same offline failure.
- Dialog and sheet titles use shared sizing, the Fast switch occupies less horizontal space, and quota bars use a more compact layout with consistent normal and near-limit colors.
- Larger loading indicators use distinct, smoothly morphing silhouettes with precomputed outlines.
- Gateway history and operation-receipt reads share their canonical readers and decoding paths; HTTP response contracts are unchanged.
- Prerelease npm publication now uses the next dist-tag without replacing stable latest packages.

## Upgrade

- Android/Gateway Protocol 4 and the database schema are unchanged. Install the signed Android APK over the existing app; do not uninstall it. Interrupted host connections still require refresh or Try again.
- Gateway and npm packages use the aligned version 3.3.0. To update the Gateway, finish active work, run `npm install -g pinkcollab@3.3.0`, then `pinkcollab update` under the existing OS user, retaining `--data-dir` when applicable. Restarting the Gateway ends active OMP runtimes but preserves stored sessions and pairings.
