PinkCollab v4.0.1: Markdown tables in Android agent replies

## Highlights

- Agent replies render GFM pipe tables with equal-width columns, wrapped cells, header styling and source-defined left, center and right alignment.
- Table cells retain inline formatting and tappable links. Long-press copies the complete original Markdown, including every cell.

## Fixes

- Identical tables in different messages keep independent layouts and invalidation callbacks. Tables measure against their message body rather than the full drawing canvas.
- Table cells reflow when conversation typography changes, even when the message width stays unchanged. Markdown parsing remains cached off the UI thread; rendered spans belong to each message view.

## Upgrade

- Protocol 4 and the database schema are unchanged. Install the signed Android APK over the existing app; do not uninstall it.
- Gateway and npm packages use the aligned version 4.0.1; Gateway behavior is unchanged from 4.0.0. To update the Gateway, finish active work, run `npm install -g pinkcollab@4.0.1`, then `pinkcollab update` under the existing OS user, retaining `--data-dir` when applicable. Restarting the Gateway ends active OMP runtimes but preserves stored sessions and pairings.
