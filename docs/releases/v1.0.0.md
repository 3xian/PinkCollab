PinkCollab v1.0.0 — protocol 3 and clearer session state

## Highlights

- Android and Gateway now use protocol 3, with separate session metadata, runtime state, command receipts, and typed WebSocket events.
- Session presentation distinguishes live runtime activity from persistent conversation history and command status.
- Work timing is measured by the Gateway, pauses while waiting for input, and freezes when a round settles. Android extrapolates timing only while connected.
- Reconnecting and switching session views retain the last visible transcript while refreshing authoritative state.

## Compatibility and upgrade

- Upgrade the Android app and Gateway together. The sole client API is `/api/v3`; older API routes return HTTP 426 (`protocol_upgrade_required`). Older Android clients and Gateways are not compatible with this release.
- Update the npm launcher with `npm install -g pinkcollab@1.0.0` and install the Android APK from this release.
- Protocol 3 is independent of OMP's local RPC version and the database schema version.
