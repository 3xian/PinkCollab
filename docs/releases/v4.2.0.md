PinkCollab v4.2.0: delete finished tasks and reuse prompts with Quick inputs

## Highlights

- Delete a task from its Session info dialog after confirmation. Deletion removes its OMP history, session artifacts and uploaded attachments while leaving project files unchanged. Exit its runtime and close any external OMP terminal using the session first.
- Save, edit and delete reusable prompts in Quick inputs beside the model and Fast controls. Tap an entry to append it to the composer; entries stay on the Android device across conversations and app restarts.
- The website includes a 30-second app demo, and the README has a larger promotional cover linking to the full-resolution image.

## Fixes

- Deleted tasks are removed from connected clients along with cached details, drafts and attachment references. Replaying an old creation request cannot recreate a deleted task, and interrupted cleanup can be retried after a Gateway restart.
- Deletion refuses active runtimes, pending commands, detected external OMP writers, linked artifact directories and shared history mappings.
- Session titles omit terminal icon-font characters while retaining standard symbols and emoji. The task-strip fade no longer washes out the floating TODO panel; Fast uses a compact pill control and timeline accents use a clearer green.
- Stopping a runtime remains available when session records or command receipts cannot be read or written.

## Upgrade

- Update both the Android app and Gateway to 4.2.0 to use task deletion. Protocol 4 is retained; the Gateway database migrates to schema 9, which older Gateway versions cannot open. Back up the Gateway data directory before upgrading if rollback may be needed.
- Install the signed Android APK over the existing app; do not uninstall it. To update the Gateway, finish active work, run `npm install -g pinkcollab@4.2.0`, then `pinkcollab update` under the existing OS user, retaining `--data-dir` when applicable. Restarting the Gateway ends active OMP runtimes but preserves stored sessions and pairings.
